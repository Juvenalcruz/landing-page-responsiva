# SENA Estética Automotiva

Site (landing page) com catálogo de preços e pedido direto pelo WhatsApp.

Arquivo único: `index.html` (HTML, CSS e JavaScript juntos, sem instalação).

## Publicar no GitHub Pages
1. Envie `index.html` para a raiz do repositório.
2. Em **Settings → Pages**, em *Build and deployment*, escolha **Deploy from a branch**, branch **main** e pasta **/(root)**.
3. Aguarde 1 a 2 minutos. O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
